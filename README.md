# Bookshelf Management System

A simple web application for managing a digital bookshelf, allowing users to add, update, delete, and search for books.

## Features

- Add new books with title, author, year, and reading status
- Update existing book information
- Mark books as read or unread
- Delete books from the shelf
- Search for books by title
- Persistent storage using localStorage

## Technologies Used

- HTML
- CSS (not included in the provided code)
- JavaScript
- Web Storage API (localStorage)

## Usage

### Adding a Book

1. Fill in the book details in the "Tambah Buku" (Add Book) form.
2. Click "Submit" to add the book to your shelf.

### Updating a Book

1. Click on the book title you want to update.
2. The book details will populate the "Tambah Buku" form.
3. Make your changes and click "Submit" to update the book.

### Marking a Book as Read/Unread

- Click the "Selesai di Baca" (Finished Reading) or "Belum selesai di Baca" (Not Finished Reading) button next to the book.

### Deleting a Book

- Click the "Hapus buku" (Delete Book) button next to the book you want to remove.

### Searching for a Book

1. Enter the book title in the search bar.
2. Press Enter or click the search button to filter the books.
